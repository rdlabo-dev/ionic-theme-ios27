# Ionic Theme iOS27

Styles and Web behavior for Ionic apps using the iOS 27 design.

```sh
npm install @rdlabo/ionic-theme-ios27
```

See the [setup guide](https://github.com/rdlabo-dev/ionic-theme-ios27#readme) for Sass, page transitions and supported Ionic versions.

For native controls, also install `@ionic-theme/capacitor-native-ui` as a direct application dependency and run `npx cap sync ios`. Legacy `/native` and `/vertical-bars` imports remain compatibility exports of that package. The theme itself no longer registers a Capacitor plugin.
