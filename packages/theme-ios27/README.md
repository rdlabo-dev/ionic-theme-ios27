# Ionic Theme iOS27

Styles and Web behavior for Ionic apps using the iOS 27 design.

```sh
npm install @rdlabo/ionic-theme-ios27
```

See the [setup guide](https://github.com/rdlabo-dev/ionic-theme-ios27#readme) for Sass, page transitions and supported Ionic versions.

For native controls, also install `@ionic-theme/capacitor-native-ui` as a direct application dependency and run `npx cap sync ios`. Import native APIs from `@ionic-theme/capacitor-native-ui` and vertical bar APIs from `@ionic-theme/capacitor-native-ui/vertical-bars`. The former theme `/native` and `/vertical-bars` entry points have been removed. The theme itself no longer registers a Capacitor plugin.
